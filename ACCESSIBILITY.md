# Accessibility

## Commitment and interfaces

The project aims to make its documentation, examples, and contribution process usable
by people with different abilities and experience levels. Contributions that improve
readability, navigation, and access to information are welcome.

`hlib` is a Helm library chart. Its primary interfaces are text files, generated
Kubernetes manifests, Markdown documentation, and Helm commands. Documentation and
community interactions are available through GitHub; chart documentation is also
published on the [repository website](https://anatolek.github.io/helm-charts/).

## Environments and limitations

Contributors use their own terminal, editor, browser, and assistive technology.
Accessibility can depend on those tools and on GitHub's interface. This statement
does not certify compatibility with particular screen readers, browsers, or assistive
tools, or claim a formal accessibility conformance level.

Some documentation uses wide tables and long YAML examples that may require
horizontal scrolling or be difficult to navigate. Prefer meaningful headings,
descriptive links, and copyable text examples when improving documentation. Avoid
making screenshots or color the only way to understand a result.

## Report a barrier

Open an [issue](https://github.com/anatolek/helm-charts/issues/new/choose) describing
the affected page or example, the task you were trying to complete, and the barrier.
Include the browser, terminal, editor, or assistive tool and version if relevant, and
suggest an alternative format if it would help. You do not need to disclose a
disability or medical information.

For a report that includes personal information you prefer to keep private, contact
[anatolek@ukr.net](mailto:anatolek@ukr.net). Accessibility improvements are reviewed
through the normal contribution process; see [CONTRIBUTING.md](CONTRIBUTING.md).
