# Support

## Find documentation and examples

Start with the [repository README](README.md), the
[`hlib` reference](charts/hlib/README.md), and the
[consumer examples](charts/hlib/examples/README.md). For development and local checks,
read [CONTRIBUTING.md](CONTRIBUTING.md).

## Choose a channel

- Ask usage questions and discuss approaches in
  [GitHub Discussions](https://github.com/anatolek/helm-charts/discussions).
- Report reproducible bugs and propose features through the
  [issue templates](https://github.com/anatolek/helm-charts/issues/new/choose).
- Report suspected vulnerabilities privately using [SECURITY.md](SECURITY.md).
- Report conduct concerns using [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- See [ACCESSIBILITY.md](ACCESSIBILITY.md) for reporting accessibility barriers.

Search existing issues and discussions before opening a new one. Support depends on
maintainer and community availability; there is no guaranteed response time.

## Make a question or report actionable

Include the `hlib` version, Helm version, relevant Kubernetes version, the template
include you use, and a small example of the values. Explain the result you expected,
what happened, and the commands needed to reproduce it. Paste text in code blocks
where possible so it can be searched, copied, and read with assistive tools.

Sanitize manifests and logs before sharing them. Do not post credentials, tokens,
private keys, personal data, or real Kubernetes Secret values. Base64-encoded values
are not redacted secrets.
